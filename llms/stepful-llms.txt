# Stepful

> education for entry-level allied-health roles in as little as four months, through live,
> cohort-based online programs paired with 1:1 coaching, at-home clinical skills kits and
> employer-site clinical rotations, then places graduates into hospital and clinic jobs.

## What an agent can and cannot do here

**Stepful publishes no public API.** As of 2026-08-29 there is no OpenAPI, Swagger, GraphQL
SDL, AsyncAPI, MCP server, A2A agent card, webhook catalog, SDK, CLI, developer portal or
API reference on any host Stepful operates. Both of its applications are
authenticated-only: `classroom.stepful.com` (student learning) and `admin.stepful.com`
(staff administration), each a Rails/Devise session login. There is nothing here for an
agent to call. Everything below is a human-readable web page.

Two hostnames under stepful.com DO serve APIs, and neither is Stepful's:

- `c.stepful.com` is a CNAME to Converge (runconverge.com), a marketing-attribution
  platform. It serves a FastAPI OpenAPI at `/api/openapi.json` and an MCP endpoint at
  `/api/mcp` whose OIDC issuer is `https://app.runconverge.com/api/mcp`. The spec describes
  ad platforms, pixels, attribution dashboards and Shopify/Amazon data sources — Converge's
  product, not Stepful's.
- `k.stepful.com` is a PostHog analytics reverse proxy (`*.proxyhog.com`).

Do not treat either as a Stepful integration surface.
